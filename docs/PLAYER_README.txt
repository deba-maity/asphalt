ASHEN VOW {VERSION} — WINDOWS CANDIDATE

Extract the complete ZIP into a new folder. Open AshenVow.exe.
Keep the executable, BUILD.json, README and notices together. Game data is
embedded in the executable; Godot, Python and a network are not required.
An APK is for Android phones/tablets, not this Windows laptop. No APK is supplied.

This is an unsigned candidate. No signing certificate is configured.
Verify SHA-256 using SHA256SUMS.txt from the same release. Do not disable security
software. Download only from the project repository chosen by its owner.

PLAY
New Game starts Rayan's ordinary day; replacing progress asks for confirmation.
Follow the objective and speak to Mira, then Saren. Light/heavy attacks, guard,
parry, dodge and stamina matter. R drinks a healing draught. Rest at shrines to
refill health/healing and save a checkpoint. Continue returns to that checkpoint.
Ordinary combat death retries it; authored story events progress separately.
After the ending, Continue stays at the memorial. Chapter replay saves separately.

DEFAULT CONTROLS
WASD move; mouse camera; Shift sprint; Space dodge; LMB light; RMB heavy;
Left Ctrl guard/parry; Q lock; E interact/advance; R heal; F later ability;
Tab journal/help; Escape pause. Arrow keys and Enter navigate/confirm menus.
Controller: sticks move/orbit, X/Y attacks, LB guard, B dodge, RB lock,
A interact, D-pad up heal, LT later ability, stick click sprint, Back journal,
Start pause. Physical controller acceptance remains outstanding.

SETTINGS
Play: Story/Standard, subtitle sizes, sensitivity/inversion, reduced effects,
optional shake. Controls: keyboard/mouse rebinding. Audio: separate volumes.
Display: 540p/720p/900p 3D, 30/60 cap, window/fullscreen and shadows.
Start with 720p/30. A 60 FPS cap is optional, not a performance guarantee.

SAVES, LOGS AND UPDATES
Windows: %APPDATA%\AshenVow\
progress.json, progress.backup.json, settings.cfg, logs\godot.log.
Back up this whole folder while the game is closed. Opening-chapter schema-one
saves migrate with an original backup. Future saves are refused safely.
For an update, extract the new ZIP into a separate game folder. Do not delete
your AppData save folder. Keep its backup until the update has been checked.

TROUBLESHOOTING
No launch: confirm you extracted the ZIP fully, chose Windows x86_64 and have
working OpenGL 3.3-capable graphics drivers; keep the error/log for an issue.
Low FPS: start plugged in as you normally play, choose 540p, disable shadows
and keep the 30 FPS cap. No laptop performance is guaranteed or measured yet.
Lost mouse: Escape pauses/releases it; click Resume and release held actions.
Silent audio: check game bus/master levels and Windows output selection.
Failed transition: use the recovery/checkpoint button; do not delete progress.
Damaged save: preserve both progress files and logs; the game tries its valid
previous backup. Never edit or damage your only copy for testing.

KNOWN LIMITS
All six chapters and an ending are playable, but the campaign is short.
The multi-hour goal is unmet. Stylized hard-jointed art/animation and synthesized
audio need human acceptance. Full rendered review, physical inputs and the
Ryzen 5 5500U laptop benchmark remain untested. Headless tests are not FPS proof.
