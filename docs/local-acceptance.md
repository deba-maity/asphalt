Complete the three echoes, checking that movement, guard/roll and openings are understandable before the Warden. Confirm that each next encounter restores health/draughts, loss retries the current encounter, and direct Warden practice is available. Try light/heavy, advancing cut, guard/parry, roll, lock, heal, composure break and riposte. Check feedback/animation/sword/foot/camera collision visually and listen to buses. Check focus loss, physical controller/disconnect, remapping, subtitle sizes, fullscreen/window/resize and Story/Standard.
3. Separately open **Earlier campaign - prototype archive**; use New Game for Mira/Saren, checkpoint/shrine and old chapter checks. Quit/relaunch Continue from a checkpoint; check settings and discoveries. Back up AppData before migration tests. Load an actual schema-one copy, verify its retained original and progression. Never corrupt the only player save.
4. Traverse all chapters through chapter cards, betrayal/canonical death, Keeper/trial, resurrection, returned abilities, late bosses, two-phase final encounter, ending/credits and memorial Continue. Confirm ordinary death does not replay canonical resurrection; checkpoint rewards cannot be farmed. Check separate chapter replay preserves campaign Continue.
5. Follow [benchmark.md](benchmark.md) for at least 15 minutes of rendered route and a longer normal play session. Start with the Display **Lower power** preset (540p/30, no shadows/MSAA), then compare Balanced (720p/60) under the same conditions; report frame distributions/spikes, transition timings and process memory. Inspect errors over repeated load/save/quit and thermal behavior. F9 captures actual current-build evidence with metadata.
6. Mark each item **Passed**, **Failed**, or **Not run (reason)** with timestamp/machine/build. Report logs and reproduction steps.
